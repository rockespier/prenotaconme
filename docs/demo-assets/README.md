# Recursos del cliente demo

Negocio inventado **Barbiere Navigli** (Milán) para la demo con el primer cliente. Se suben desde el backoffice cuando esté F5-08 (logo y portada del negocio).

| Archivo | Uso |
|---|---|
| `barbiere-navigli-logo.svg` / `.png` (512×512) | Logo del negocio (cabe en un avatar redondo) |
| `barbiere-navigli-cover.svg` / `.webp` (1600×600) | Portada de la página de reserva; la zona izquierda es oscura para el nombre en blanco |

Los textos están convertidos a trazos con Figtree (SIL Open Font License), así que no dependen de fuentes instaladas. El logo de la plataforma está en `src/frontend/prenotaconme-web/public/brand/`.
